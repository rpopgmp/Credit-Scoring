# Credit-Scoring

Была решена задача кредитного скоринга.
Использовался алгоритм отбора признаков TSFFS
Классификаторы: CatBoost, RandomForest

Датасет:
https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data
Результаты:

CB:
Accuracy: 0.7500
F1-score: 0.8276
Precision: 0.8054
Recall: 0.8511
ROC-AUC: 0.7556

RF:
Accuracy: 0.7600
F1-score: 0.8442
Precision: 0.7784
Recall: 0.9220
ROC-AUC: 0.7191
